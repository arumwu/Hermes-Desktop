# 繁體中文

在「設定 → 外觀 → 介面語言」選擇「繁體中文」。選擇「跟隨系統」時，`zh-Hant` 或台灣、香港、澳門的中文系統會使用 `zh-TW`；簡體中文與 English 選項仍然保留。

介面標籤、設定、任務、語音、更新、錯誤提示、選單與輔助使用名稱使用繁體中文。對話正文、伺服器內容、使用者檔名、路徑與網址保留原文。系統日期格式使用台灣地區。

`desktop-zh-TW.json` 以原有標籤作為查找鍵，`messages-zh-TW.json` 保留原有訊息 ID 與格式參數。動態訊息僅翻譯固定文字，插入的使用者資料不轉換，也不重複求值。新增標籤時，請同步更新語系資源。執行時不需要 OpenCC。

本儲存庫的預設 README、說明文件與 `.zh-TW.md`／`.zh-TW.txt` 副本皆使用繁體中文。完整入口見 [全部繁體中文文件](README.md)。原作者歷史內容可由 Git 記錄追溯；原始驗證資料及第三方授權全文保留。

驗證指令（JDK 21）：

```sh
./gradlew test -PheadlessTests=true
./gradlew renderTraditionalPreviews
```

畫面輸出在 `build/previews-zh-TW`，包括登入、設定、桌面助理、全部設定分頁、預設對話標題、說明、首頁、任務、對話框與檔案。測試涵蓋語言辨識、訊息參數、使用者內容保留及原有語言切換。

切換語言後，既有快取中的「`新会话`」等預設標題只在畫面上顯示為「新對話」，不修改伺服器或本機儲存的標題。自訂標題保留原文。畫面測試會檢查單擊／雙擊提示及快取標題，避免只測試空白首頁。

既有內建提示詞以穩定 ID 與原始預設內容辨識。未修改的欄位會隨語言顯示及插入繁體版本，已編輯欄位保留原文；不需要按「恢復預設」覆蓋自訂片段。
